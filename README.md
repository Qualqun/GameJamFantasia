# Sunbreeze

**Sunbreeze** is a game jam project developed in **3 days** with a team of **12 people**, using **Unreal Engine** and **C++**.

The project was created as a short production challenge, focused on quickly building and integrating gameplay features, interactions, sound, and music inside Unreal Engine.

---

## Production Details

- **Duration**: 3 days  
- **Team Size**: 12 people  
- **Engine**: Unreal Engine  
- **Language**: C++  

---

## Game Overview

**Sunbreeze** is a fast-paced game jam project built around a compact gameplay experience.  
The project focused on rapidly prototyping and integrating multiple gameplay elements, while ensuring that the different systems could interact properly with each other.

The short development time required quick iteration, clear task prioritization, and efficient integration of gameplay, audio, and interaction systems.
